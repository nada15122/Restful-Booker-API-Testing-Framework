# 🚀 Restful Booker API Testing Project

## 📌 Project Overview
This project involves comprehensive **API Testing** for the **Restful Booker** system. It covers the full lifecycle of API testing, from analyzing requirements and designing test cases to automated execution and professional reporting.

## 🛠 Tools & Technologies
* **Postman:** Collection development, environment management, and script writing.
* **JavaScript:** Used for writing automated assertions within Postman.
* **Newman:** Command-line tool used to run the Postman collection.
* **Newman-reporter-htmlextra:** Generated professional and detailed HTML execution reports.

## 📊 Test Coverage & Highlights
* **Total Test Cases:** 35 Test Cases.
* **Modules Covered:**
    * **Auth:** Token generation and access control.
    * **Booking:** CRUD operations (Create, Get, Update, Partial Update, Delete).
    * **HealthCheck:** Verifying API availability.
* **Verification Types:** * Functional validation of responses.
    * Status code assertions (200, 201, 404, etc.).
    * Response body structure and data types.
    * Performance thresholds (Response time < 500ms).

## 🚀 How to Run the Project
To run this collection on your local machine, follow these steps:

1. **Install Newman:**
   ```bash
   npm install -g newman

2.Install the HTML Extra Reporter:
   ```bash
npm install -g newman-reporter-htmlextra

3.Run the Collection:
newman run Restful-Booker.postman_collection.json -e booking.postman_environment.json -r htmlextra

🐞 Bug Reporting
During the testing phase, several critical issues were identified and documented, including:

Inconsistent status codes (e.g., receiving 405 Method Not Allowed instead of 404 Not Found).

Logic errors in booking updates and performance violations for specific endpoints.
